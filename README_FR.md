# Guide d'Installation et d'Utilisation - Valheim VR (VHVR) en Français

Bienvenue dans la version améliorée et francisée de **VHVR (Valheim VR Mod)**, optimisée pour les versions récentes de Valheim (Unity 6 / Ashlands / Bog Witch).

---

## ⚡ 1. Installation Rapide en 1 Clic

1. Double-cliquez simplement sur :
   👉 **`Installer-ValheimVR-FR.cmd`**
2. Le script va :
   - Détecter automatiquement votre jeu Valheim (ex: `D:\SteamLibrary\steamapps\common\Valheim`).
   - Déployer BepInExPack Valheim et le mod VR compilé en français.
   - Installer les plugins SteamVR / OpenVR 64 bits et les profils de contrôleurs (Oculus Touch, Valve Index, HTC Vive).
   - Créer un raccourci **"Valheim VR (Français)"** sur votre Bureau.

---

## 🎮 2. Comment Lancer le Jeu en Réalité Virtuelle

1. Démarrez votre casque VR :
   - **Meta Quest 2 / 3 / Pro :** Connectez-vous via Quest Link, AirLink ou Virtual Desktop.
   - **Valve Index / HTC Vive :** Assurez-vous que vos stations de base et manettes sont allumées.
2. Lancez **SteamVR** sur votre PC.
3. Lancez le jeu via le raccourci sur votre Bureau ou directement depuis Steam.
4. Dans le casque, les menus et les options du mod apparaîtront **automatiquement en français** !

---

## 🛡️ 3. Nouvelles Fonctionnalités & Améliorations Apportées

### A. Vignette Dynamique de Confort (Anti-Cinétose)
- **Objectif :** Réduire la sensation de nausée ou de vertige sans gâcher la vue.
- **Effet :** Assombrit doucement les bords du champ de vision lors des mouvements brusques :
  - Rotations rapides de la caméra ou de la tête.
  - Sprints et courses effrénées.
  - Navigation sur les vagues et tempêtes en bateau.
- **Réglages :** Ajustable dans les options en jeu sous l'onglet **"Confort Anti-Cinétose"**.

### B. Lissage & Stabilisation de Visée à l'Arc
- **Objectif :** Éliminer les tremblements naturels des mains et manettes VR.
- **Effet :** Applique un filtre de lissage sphérique doux (Slerp) sur l'arc lorsque la corde est tirée, vous permettant d'abattre vos cibles à grande distance avec précision.
- **Réglages :** Ajustable dans les options en jeu sous l'onglet **"Contrôles Gestuels"**.

### C. Interface et Menus Entièrement Traduits
- Les onglets de réglages, les libellés d'options, les valeurs et les bulles d'aide sont désormais traduits en **français clair et immersif**.

---

## 🔄 4. Restauration / Désinstallation (100% Réversible)

Si vous souhaitez revenir à la version originale en écran plat sans réinstaller le jeu :
- Double-cliquez simplement sur :
  👉 **`Desinstaller-ValheimVR-FR.cmd`**
- Il retirera les modules VR et restaurera le fonctionnement standard de Valheim en quelques secondes.
